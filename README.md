# All Aboard

Mobile-first employee onboarding and certification management platform.

## Development status

Private development repository. The latest verified application source and automated tests will be imported from the All Aboard V35 development checkpoint before further implementation.

## Working rules

- Commit and push tested development milestones to a dedicated development branch.
- Keep the main branch stable; do not deploy automatically.
- Never commit real employee credentials, certificate records, passwords, secrets, or personal data.
- Preserve compatibility with existing wallet data and backups.
- Run automated checks and record any unverified Android or browser behavior.
- No paid services or deployments without explicit approval.
